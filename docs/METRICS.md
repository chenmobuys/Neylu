# 指标定义与兼容性

- CPU 使用系统核心计数器，按全部核心计算用户、系统与空闲占比，范围 0–100%。
- CPU 温度通过只读 AppleSMC 协议按 Intel、Apple M1–M5 的独立映射读取，最多每 5 秒更新。Apple Silicon 使用有效 CPU 热区平均值，Intel 优先采用有效 CPU diode/die 读数；不是每核心一传感器。未知型号显示不支持，无读数时显示不可用，不写 SMC、不控制风扇。
- GPU 使用 IOKit 性能统计。不同芯片或 macOS 版本可能没有对应注册表键，不可用不伪装为零。缺失的 Renderer/Tiler 保存为 NULL，实际 0 保持为 0；仅对整个可见历史中完整可用的指标等权堆叠，总高度为其平均值，不代表三种互斥占用。
- 网速使用单个主接口的字节计数差，不叠加物理网卡和 VPN 隧道；主接口变化会重新建立采样基线。无主路由时回退到活动 en 接口。
- 十进制单位 1000 进位，二进制单位 1024 进位；网速每行都带 /s，容量也遵循所选进位，百分比不变。
- 内存使用 App（匿名页减可清除页）、联动与压缩内存之和；不包含可回收文件缓存。图表展示使用量，不是内存压力。
- 启动盘容量为共享容器统计，每 10 秒更新。Disk Arbitration 定位启动卷后沿 I/O Registry 父链查找物理磁盘计数差；同一物理盘其他卷 I/O 也包含在内，不合计磁盘镜像。
- 外接磁盘通过 Disk Arbitration 识别已挂载的外部本地硬件卷，排除 DMG、网络挂载和隐藏卷。插拔及改名通知触发重新发现，并每 10 秒刷新容量与列表；加密卷解锁并挂载后才显示。每个卷展示其所在物理磁盘的 I/O，多分区的数值可能相同，不应相加；不支持时显示不可用。重新连接先建立计数基线，不将累计计数当成即时速度。
- 启动时间为当前时间减内核 kern.boottime，包括睡眠；读取失败显示不可用。
- 历史使用真实时间坐标。两分钟窗口之外的数据不会移到当前时间冒充新记录；暂停采样时只连线，不写虚构值。

## 验证范围

本机 Apple M3 Max 上验证过 CPU、温度、GPU、内存、网速、磁盘容量与 I/O。
虚拟机 CI 只覆盖可用的系统采样与历史、格式化、打包逻辑，不能证明其他型号的传感器支持。
部署目标为 macOS 12，主程序、更新辅助程序与登录辅助应用均使用该目标编译。macOS 12–25 的材质回退分支曾在当前系统强制运行检查；尚未在 macOS 12 实机验证，不能将当前系统上的编译与回归测试等同于旧系统实测。
macOS 13+ 使用 SMAppService 管理开机启动；12 使用打包在 App 内的登录辅助应用和 SMLoginItemSetEnabled。图表鼠标跟踪统一使用 AppKit。macOS 11 缺少当前使用的 Canvas、TimelineView 与原生 Markdown 能力，暂不支持。
睡眠、多显示器、VPN 切换和各种辅助功能外观仍欢迎真实环境反馈。

刷新间隔可选 1、2、5、10 秒，默认 2 秒，选择跨重启保存。切换仅替换采样定时器，不重建详情窗口或设置菜单；图表最多表示最近两分钟：启动初期按已有采样铺满宽度，随数据积累逐渐压缩；满两分钟后使用固定滚动窗口，近期记录全部过期后重新自适应展开。CPU 温度最多每 5 秒读取一次，硬盘容量最多每 10 秒更新一次。

外接磁盘弹出使用 [NSWorkspace.unmountAndEjectDevice(at:)](https://developer.apple.com/documentation/appkit/nsworkspace/unmountandejectdevice%28at%3A%29)。调用在后台执行，状态及错误回到主线程；实际执行前重新核对当前挂载卷及 UUID。仅外接卷提供按钮，系统盘没有弹出入口；失败保留系统错误，不调用强制卸载或 shell 命令。

菜单栏显示配置只影响菜单栏的内容与顺序，详情和历史仍保留完整监控指标。网速的上传/下载作为一组；系统盘占用使用启动盘数据。每个指标预留固定宽度，切换单位或显示配置时才改变整体宽度，定时数值刷新不重新排列列表。全部隐藏时保留应用图标及点击入口。

所有硬件采样由后台串行队列持有，主线程只发布结果。重复请求合并；睡眠前的旧结果不会覆盖唤醒后的状态。历史数据库与 WAL 使用 0600 权限，默认历史目录为 0700。存储失败时后台缓存最多保留一天最快采样量，自动重试最多每 30 秒一次。

开发分支的交互样式：macOS 14+ 图表使用底部细线提示键盘焦点，提高对比度时加深加粗；12/13 保留系统原生焦点框。鼠标悬浮读数与左右方向键查阅使用同一时间指示线。更新、关于、更新日志及菜单栏设置窗口在非键盘打开时不预选首个链接或控件，Tab 仍进入原生焦点顺序。详见 CHANGELOG 的 Unreleased；不代表历史发布版本已经包含这些样式。
