# 指标定义与兼容性

- CPU 使用系统核心计数器，按全部核心计算用户、系统与空闲占比，范围 0–100%。
- CPU 温度在详情可见或菜单栏温度指标启用时通过只读 AppleSMC 协议按 Intel、Apple M1–M5 的独立映射读取，最多每 5 秒更新。Apple Silicon 使用有效 CPU 热区平均值，Intel 优先采用有效 CPU diode/die 读数；不是每核心一传感器。无受支持且可读取的来源时隐藏，暂时无读数时显示不可用，不写 SMC、不控制风扇。
- GPU 使用 IOKit 性能统计。不同芯片或 macOS 版本可能没有对应注册表键，不可用不伪装为零。缺失的 Renderer/Tiler 保存为 NULL，实际 0 保持为 0；仅对整个可见历史中完整可用的指标等权堆叠，总高度为其平均值，不代表三种互斥占用。
- 网速使用单个主接口的字节计数差，不叠加物理网卡和 VPN 隧道；主接口变化会重新建立采样基线。无主路由时回退到活动 en 接口。
- 十进制单位 1000 进位，二进制单位 1024 进位；网速每行都带 /s，容量也遵循所选进位，百分比不变。
- GPU 核心数在当前采样器内缓存；网络地址仅在详情可见时读取并缓存最多 10 秒，接口变化、断网、重新打开或唤醒后失效，带宽计数器仍逐次读取。
- 内存使用 App（匿名页减可清除页）、联动与压缩内存之和；不包含可回收文件缓存。图表展示使用量，不是内存压力。
- 启动盘容量为共享容器统计，详情可见或菜单栏展示系统盘时最多每 10 秒更新。Disk Arbitration 定位启动卷后沿 I/O Registry 父链查找物理磁盘计数差；同一物理盘其他卷 I/O 也包含在内，不合计磁盘镜像。
- 外接磁盘通过 Disk Arbitration 识别已挂载的外部本地硬件卷，排除 DMG、网络挂载和隐藏卷。插拔及改名通知触发重新发现，详情可见时最多每 10 秒刷新容量与列表；加密卷解锁并挂载后才显示。每个卷展示其所在物理磁盘的 I/O，多分区的数值可能相同，不应相加；不支持时显示不可用。重新连接先建立计数基线，不将累计计数当成即时速度。
- 启动时间为当前时间减内核 kern.boottime，包括睡眠；读取失败显示不可用。
- 历史使用真实时间坐标。两分钟窗口之外的数据不会移到当前时间冒充新记录；暂停采样时只连线，不写虚构值。

## 验证范围

本机 Apple M3 Max 上验证过 CPU、温度、GPU、内存、网速、磁盘容量与 I/O。
虚拟机 CI 只覆盖可用的系统采样与历史、格式化、打包逻辑，不能证明其他型号的传感器支持。
部署目标为 macOS 12，主程序、更新辅助程序与登录辅助应用均使用该目标编译。macOS 12–25 的材质回退分支曾在当前系统强制运行检查；尚未在 macOS 12 实机验证，不能将当前系统上的编译与回归测试等同于旧系统实测。
macOS 13+ 使用 SMAppService 管理开机启动；12 使用打包在 App 内的登录辅助应用和 SMLoginItemSetEnabled。图表鼠标跟踪统一使用 AppKit。macOS 11 缺少当前使用的 Canvas、TimelineView 与原生 Markdown 能力，暂不支持。
睡眠、多显示器、VPN 切换和各种辅助功能外观仍欢迎真实环境反馈。

刷新间隔可选 1、2、5、10 秒，默认 2 秒，选择跨重启保存。切换仅替换采样定时器，不重建详情窗口或设置菜单；图表范围可选两分钟（默认）、十五分钟、一小时并跨重启保存。以下自适应规则按所选范围生效：启动初期按已有采样铺满宽度，随数据积累逐渐压缩；达到所选时长后使用固定滚动窗口，近期记录全部过期后重新自适应展开。CPU 温度最多每 5 秒读取一次，硬盘容量最多每 10 秒更新一次。

外接磁盘弹出使用 [NSWorkspace.unmountAndEjectDevice(at:)](https://developer.apple.com/documentation/appkit/nsworkspace/unmountandejectdevice%28at%3A%29)。调用在后台执行，状态及错误回到主线程；实际执行前重新核对当前挂载卷及 UUID。仅外接卷提供按钮，系统盘没有弹出入口；失败保留系统错误，不调用强制卸载或 shell 命令。

菜单栏显示配置只影响菜单栏的内容与顺序，详情和历史仍保留完整监控指标。网速的上传/下载作为一组；系统盘占用使用启动盘数据。每个指标预留固定宽度，切换单位或显示配置时才改变整体宽度，定时数值刷新不重新排列列表。全部隐藏时保留应用图标及点击入口。

所有硬件采样由后台串行队列持有，主线程只发布结果。重复请求合并；睡眠前的旧结果不会覆盖唤醒后的状态。历史数据库与 WAL 使用 0600 权限，默认历史目录为 0700。存储失败时后台缓存最多保留一天最快采样量，自动重试最多每 30 秒一次。

alpha.7 起的交互样式：macOS 14+ 图表使用底部细线提示键盘焦点，提高对比度时加深加粗；12/13 保留系统原生焦点框。鼠标悬浮读数与左右方向键查阅使用同一时间指示线。更新、关于、更新日志及菜单栏设置窗口在非键盘打开时不预选首个链接或控件，Tab 仍进入原生焦点顺序。详见 CHANGELOG 的 alpha.7；更早发布版本保留当时的交互样式。

## 省电与历史查看

省电模式选项按「跟随系统、开启、关闭」排列，默认关闭；「跟随系统」随 macOS 低电量模式调整。生效时仅把详情关闭后的采样间隔调整为 `max(5 秒, 用户设定间隔)`；打开详情恢复用户设定，系统电源状态通知在主线程更新调度。睡眠、退出状态阻止定时器被窗口隐藏回调重新启动。

后台仍保存 CPU、GPU、内存、网络的真实采样。系统盘读写与外盘查询在详情关闭时暂停；温度仅在详情可见或菜单栏温度启用时持续采样；重新打开会重建磁盘读写基线，第一帧不可用，不把关闭期间累计字节当成即时峰值。菜单栏只在实际显示文本或配置变化时重新生成位图，隐藏图表不准备绘制点。

长范围从 SQLite 在后台读取，合并读取期间的新采样；快速切换范围时只接受最后一次请求的结果。内存最多保留所选一小时原始记录，存储仍保留 24 小时。每条曲线最多绘制 240 个真实点，按多通道分桶保留各指标高低值及首尾点；不写平均值或虚构采样。GPU 缺失指标的可用性根据完整可见记录判断，不因缩减绘图点而变成可用。

## 显示选项与稳定性验证

菜单栏内存固定显示使用率，网速为字节每秒，按统一的十进制/二进制偏好换算；详情维持字节读数。固定图表会保留可见的四份降采样数据与时间范围，真实历史继续滚动记录。IP 隐藏同时遮蔽文字、悬浮提示和辅助功能读数，不影响采样。恢复默认布局不清理任何历史。

原生回归包含隔离的快捷键冲突与回滚、显示单位边界、菜单栏图像宽度，以及模拟一天采样时固定图表与持续记录的检查；模拟时间不等于一天真机运行验证。macOS 12 真机、其他芯片、多屏切换及真实 VPN 变化仍需要对应环境验证。

## 紧凑显示与温度指标（alpha.8 起）

菜单栏内存只显示百分比，保持固定窄宽度；详情仍显示已用、可用和总容量。CPU 温度是默认关闭的独立菜单栏指标，沿用已有温度传感器与校验，显示一位小数及 °C，无有效读数时显示“—”。仅在详情可见或温度指标启用时请求温度采样；温度启用不会连带恢复后台磁盘、IP 或外接盘采样。省电模式与已有传感器缓存仍生效。

图表提示的横坐标跟随选中时间，并按提示宽度限制在图内；固定状态在标题中明确显示。单位进制统一在偏好设置中管理，网速固定为字节每秒，菜单栏内存固定为百分比；单位进制同时影响详情。快捷键录入必须显式激活输入框，收到合法组合后才启用保存；支持 Control、Option 或 Command＋Shift 组合，保留冲突回滚与物理键位绑定。

## 支持检测与隐藏规则（alpha.8 起）

能力信息与当次读数分别记录。CPU、内存、网速和容量使用所支持 macOS 的通用系统接口；GPU 总体利用率必须实际检测到对应的数值计数器（真实 0 也是有效值），温度必须发现可访问且类型受支持的传感器键，并取得有效温度。没有可用来源的可选指标不会出现在菜单栏、详情或菜单栏设置的勾选与排序行中。Renderer、Tiler、核心数及磁盘读写分别确认；磁盘读写源在建立速率基线前即可确认，避免把第一次采样误当作不支持。

同一进程内已检测到的数据源不会因为断网、暂时错误或省电暂停而被撤销；温度在启动和唤醒后探测，只有详情或所选温度指标需要时才持续取值。隐藏是运行时过滤，不修改持久化的勾选、隐藏项顺序或历史记录。排序通过可见行映射到原始配置位置，避免隐藏行造成拖动和键盘排序错位。README 中英文同步说明支持条件，不承诺所有型号提供相同读数。

菜单栏窗口仅保留预览、勾选排序和指标标题行的恢复默认。隐藏 IP 不在该窗口提供，只通过详情 IP 旁的眼睛按钮操作；原有隐私状态仍保留。

## 展示稳定性

菜单栏默认保持紧凑间距，可在「菜单栏显示…」选择标准间距；显示选择、排序和间距一起保存，恢复默认布局也会恢复紧凑间距。速率字段预留覆盖单位切换的固定宽度，数值变化不触发菜单栏宽度调整；仅配置或单位进制变化需要重新布局。

网络提示分行展示最近真实采样的下载和上传速率，使用完整历史数据查找而非图表抽稀后的读数。自适应纵轴保持线性：少于 20 个采样时使用实际最大值；之后以全部可见原始速率的第 90 百分位三倍为参考（最低 1024 B/s），不超过实际峰值，再预留 10% 顶部空间。超过量程的尖峰在图边以三角标记，并显示量程；原始速率、历史及悬浮读数不变。

外接磁盘保留当前会话中已有的展示顺序，新盘追加到末尾；长名称居中截断并悬浮显示全名，主指标仍位于外盘之前。弹出继续调用 NSWorkspace，失败时保留系统原因并补充系统恢复建议或磁盘忙提示，不强制卸载。
